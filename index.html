02 Research & ongoing work

What I’m working on now.

Two open questions: how to retrieve information responsibly, and how to help coding agents learn from execution feedback.

Ongoing research

PAFR / Federated retrieval

Privacy-Aware Adaptive Federated Routing

How can a retrieval system find useful information across departments while respecting who is allowed to see it?

This work explores selective, permission-aware routing for federated RAG and answers that disclose only the information needed. Comparisons using synthetic data are planned.

Project notes / 01

FastBus.

Connecting a booking interface to the rules and data that make it work.

The application

A full-stack semester project for route search, seat availability, booking and cancellation, with role-protected administration.

How it works

Flask, PostgreSQL, and SQLAlchemy connect the booking flow to database schemas, JWT authentication, and automated migrations. Docker Compose provides the local service setup.

Project context

This is a demonstration application. Payment flows are simulated.

Project notes / 02

South-Stack.

Helping an image become the starting point for a web interface.

The application

A collaborative CSE327 group project: an AI assisted browser IDE with a virtual filesystem, code editing, and a plan, execute, verify workflow.

Image-to-design workflow

A local vision worker, design orchestration, and UI integration connect reference images to the browser development environment.

The stack

Project notes / 03

Speech Intelligence.

Exploring what a short audio recording can tell us.

Three tasks

Command recognition with a custom PyTorch CNN, speaker identification with a linear SVM, and a Whisper Base transcription baseline.

Connecting the parts

Flask APIs connect the models to browser recording, bringing the different audio tasks into one application flow.

Project context

A local educational prototype. The repository includes setup instructions, evaluation details, and the limitations of the models.

Read the code & setup

Project notes / 04

FabricFlow.

One workspace for the day-to-day operations of a fabric business.

The application

An operations dashboard for orders, inventory, customers, carriers, employees and attendance, machine assignments, and printable invoices.

Keeping records consistent

Transactional orders validate available stock. Invoices preserve historical sale prices, while authenticated administration, prepared database statements, and CSRF protection support the management workflow.

The stack

PHP 8.1+, MySQL 8+, HTML, CSS, and native mysqli. The repository includes local setup instructions.

Read the code & setup
